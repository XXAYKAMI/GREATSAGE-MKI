# SERAPHIM PROJECT - Installation Guide

## Quick Start

After cloning the repo, run:

```bash
cd THE_SERAPHIM_PROJECT
npm install
npm link
```

Then you can run from anywhere:
```bash
greatsage
```

## Options

```bash
greatsage --help    # Show help
greatsage --version # Show version
greatsage           # Start interactive mode
```

## Commands

| Command | Description |
|---------|-------------|
| `help` | Show all commands |
| `status` | View magicules & stats |
| `model` | Select AI model |
| `chat` | Interactive chat |
| `entities` | Browse entities |
| `names` | Browse names |
| `feed <file>` | Earn magicules |
| `bind` | Bind entity |
| `exit` | Quit |

